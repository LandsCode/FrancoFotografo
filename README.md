Franco Fotógrafo - Landing Page

¡Bienvenido/a al repositorio de **Franco Fotógrafo**! Una landing page diseñada estratégicamente para la captación de nuevos clientes, ofreciendo una interfaz atractiva, minimalista y fácil de navegar enfocada en destacar el trabajo visual del fotógrafo Alberto Franco.

Objetivo del Proyecto
El propósito principal de esta página es convertir visitantes en clientes potenciales a través de:
* **Navegación Intuitiva:** Secciones claras (*Acerca de*, *Portafolio*, *Contacto*).
* **Diseño Responsive:** Adaptabilidad completa para una visualización perfecta en dispositivos móviles, tablets y computadoras.
* **Copywriting Optimizado:** Textos persuasivos orientados a conectar emocionalmente con marcas y proyectos exigentes.
* **SEO Básico:** Estructura semántica para mejorar el posicionamiento en buscadores.

---

Tecnologías y Herramientas Utilizadas
* **Maquetación:** HTML5 semántico.
* **Estilos:** CSS3 personalizado (Paleta de colores elegante y tipografía minimalista).
* **Interactividad:** JavaScript Vanilla (sin librerías externas).
* **Despliegue (Hosting):** Netlify.

---

Características Destacadas (JavaScript)

Visualizador de Imágenes (Lightbox Interactivo)
Para garantizar una experiencia visual inmersiva y de alta calidad, se desarrolló una funcionalidad interactiva en el portafolio:
* **Manipulación del DOM:** Se implementó un escuchador de eventos (`click event`) en las tarjetas del portafolio.
* **Dinamicidad con CSS:** Al hacer clic en cualquier fotografía, JavaScript añade dinámicamente clases de CSS para expandir la imagen en una vista superpuesta en pantalla completa, permitiendo apreciar los detalles técnicos y de iluminación de cada captura.
